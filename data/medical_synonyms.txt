# Medical synonyms for NEET-PG search (Marrow-ito-search)
#
# Format: comma-separated equivalence classes, one per line. All terms on a
# line are treated as equivalent (symmetric expansion): a query for any
# term on a line expands to the full set.
#
# Lines starting with `#` are comments. Blank lines are ignored.
# Compatible with the OpenSearch / Solr synonyms.txt format so this file
# ports forward without changes when we move to a real search engine.
#
# Editing rules:
#   - Keep terms lower-case. Matching is case-insensitive at query time.
#   - Do not include stop words (is, am, the, of, in, on, ...).
#   - For ambiguous abbreviations (MS, AD, BPD), pick the most common
#     NEET-PG meaning. Add the alternate as its own line only if needed.
#   - Multi-word terms are OK ("ulcerative colitis"); the expander handles
#     phrase matching.
